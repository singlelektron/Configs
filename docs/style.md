# 统一视觉与鼠标工作流

设计方向是暗玫瑰、细分隔线和稳定的布局。科幻感来自规整对齐、少量粉色重点和清晰的信息分组，
不使用渐变文字、发光边框或复杂仪表盘。Kitty、Neovim、LazyGit 与 Niri 桌面共用以下颜色。

| 用途 | 颜色 / 尺寸 |
| --- | --- |
| 主背景 | `#19151c` |
| 侧栏、菜单、状态栏 | `#241d29` |
| 正文 | `#ede5ec` |
| 次要信息 | `#b3a2b1` |
| 活动窗口 / 当前操作 | `#f2a5c7` |
| 链接 / 函数 / 修改提示 | `#a7b9ed` |
| 新增 / 删除 / 警告 | `#a6c7a0` / `#f08091` / `#e7c38c` |
| 提示 / ANSI 紫色 | `#9bcbd3` / `#c9adeb` |
| 非活动边框 | `#574254` |
| 编辑器选区 | `#3b2c3b` |
| Kitty 不透明度 / 内边距 | `0.94` / `8` |
| 文件树默认宽度 | 30 字符，可拖动 |

正文在实色面板上的计算对比度约为 13.27:1，次要文字为 6.80:1，玫瑰重点为 8.56:1。
普通代码、数学笔记与文件名使用中性浅色；粉色用于当前操作。ANSI 红绿黄蓝紫青仍保留各自含义，
Neovim 内置终端也采用 Kitty 的 16 色，避免 Git 增删、诊断和终端输出混成同一种粉色。

编辑区背景不指定实色，继承 Kitty 的轻微透明背景。侧栏、浮动菜单、状态栏和桌面通知使用实色，
保持文件名、菜单和诊断的可读性。macOS 使用轻量背景模糊；Linux 不依赖模糊保证文字对比度。
Kitty 的透明与模糊能力见[官方配置说明](https://sw.kovidgoyal.net/kitty/conf/#opt-kitty.background_opacity)。

桌面壁纸使用二次元人物或风景；科幻风由界面布局体现。优先选择暗色、黄昏或夜景，人物靠画面外侧，
中央阅读区域保留安静的背景。个人壁纸留在仓库外。默认 94% 不透明度减弱明亮壁纸对公式和代码的干扰，
实际视觉对比度仍需在图形会话确认。

Niri 使用约 10 像素间距、玫瑰活动边框、弱化非活动边框和轻微圆角。
三种 Waybar 信息密度共用颜色、字号与间距，按当前任务切换；输出缩放和输入设备差异留在本机覆盖中。
部署配置不启用或切换桌面会话。

微调透明度只需在本机 `~/.config/dotfiles-local/kitty.conf` 写入例如
`background_opacity 1.0`；提高数值能改善明亮或复杂壁纸上的对比度。
颜色集中在 `config/kitty/theme.conf`、`config/nvim/lua/dotfiles/ui.lua` 和
`config/lazygit/config.yml`，桌面各组件沿用同一组色值。保持小型静态配置，不额外引入主题生成器。

鼠标流程：点击文件树 → 双击文件 → 点击顶部标签切换 → 点击 Git 管理改动 → `q` 返回编辑。
键盘流程与鼠标并存：原生窗口、缓冲区和寄存器操作保持原样，文件树和 Git 也有快捷键。

## 终端颜色与配置不同

Shell 启动脚本也能通过 OSC 转义序列改写终端颜色。此次 Arch 的 Nyarch / pywal
在 `.bashrc` 中加载 `~/.cache/wal/sequences`，曾把仓库主题覆盖成暖棕色。
本机已备份并修正该加载条件，使 Kitty 使用仓库配色；shell 配置本身不纳入仓库。
如果新机器使用相同的桌面主题工具，可将原有 pywal 加载块限定为：

```bash
if [[ -z "${KITTY_WINDOW_ID:-}" && "${TERM:-}" != "xterm-kitty" && -f "$HOME/.cache/wal/sequences" ]]; then
    cat "$HOME/.cache/wal/sequences"
fi
```

修改后在 Kitty 按 `Ctrl-Shift-F5` 重载配置，或打开新窗口。相同颜色与不透明度仍会叠加
不同壁纸；macOS 的背景模糊与 Linux 合成器也可能呈现不同效果，因此不能保证像素颜色完全相同。
