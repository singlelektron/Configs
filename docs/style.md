# 统一视觉与鼠标工作流

设计使用低饱和粉紫二次元壁纸、浅樱粉启动器、深色控制中心和顶部胶囊，以及深紫灰半透明终端。
界面以紧凑列表、细分隔线和少量粉色选中提示组织信息，避免重复的大卡片和装饰标题。
不同区域按阅读用途选择明暗，不把全部应用染成同一种粉色。

| 区域 / 用途 | 颜色 / 尺寸 |
| --- | --- |
| 启动器、通知背景 | `#fff7fa` |
| 控制中心、声音/网络/蓝牙设置 | `#211c29` |
| 浅色面板正文 / 次要信息 | `#3a2932` / `#765f6c` |
| 浅色面板强调 / 选中 / 分隔线 | `#a34264` / `#f7e2eb` / `#e8cbd8` |
| 顶部胶囊、音乐岛及其展开面板 | `#211c29` |
| Kitty 主背景 / 编辑器侧栏 | `#1b1722` / `#231d2c` |
| 终端正文 / 次要信息 | `#eee5ef` / `#c1b1c7` |
| 深色界面活动状态 / 选区 | `#e6a6c7` / `#51384c` |
| 链接 / 函数 / 修改提示 | `#b7c3eb` |
| 新增 / 删除 / 警告 | `#b2c8b4` / `#f095a8` / `#e8c495` |
| 提示 / ANSI 紫色 | `#a3ccde` / `#cbb6f1` |
| Kitty 不透明度 / 内边距 | `0.86` / `8` |
| 控制中心 / 启动器默认大小 | `356 × 580` / `480 × 560` 逻辑像素 |
| 文件树默认宽度 | 30 字符，可拖动 |

普通代码、数学笔记与文件名使用中性浅色；粉紫用于选中与当前操作。ANSI 红绿黄蓝紫青保留各自含义，
Neovim 内置终端采用 Kitty 的 16 色，Git 增删、诊断和终端输出保持可区分。
编辑区背景继承 Kitty 的透明度；侧栏、浮动菜单和状态栏使用实色以稳定阅读。
透明仅作用于终端背景，文字保持不透明。macOS 配置保留轻量背景模糊；Linux 不依赖模糊保证可读性。
Kitty 的透明与模糊能力见[官方配置说明](https://sw.kovidgoyal.net/kitty/conf/#opt-kitty.background_opacity)。

壁纸以低饱和粉紫、安静柔和的画面为主，个人壁纸留在仓库外。当前默认源图为 `1920 × 1200`，
在 4K 显示器上会裁剪或放大，不是原生 4K。来源、尺寸与校验值记录在 `config/desktop/wallpaper.json`。
更换壁纸不会自动重算软件配色；明亮或复杂区域透过终端后的可读性仍需在实际显示器检查。

## 桌面组件

Niri 保留约 10 像素窗口间距、1 像素柔粉活动边、8 像素圆角与轻阴影。
默认顶部由 Quickshell 提供：左侧放控制中心入口、工作区和搜索；中央音乐岛；右侧放更新、
网络、音量、托盘和时钟。音乐岛点击展开封面、播放控制与进度；收起封面为26px并留12px水平边距。
声音入口可展开选择默认输出、拖动音量和静音，音量变化时音乐岛短暂反馈。
时钟使用等宽数字与固定字段宽度，日期、更新数、音量百分比也固定占位。
展开面板可按 Esc 或点击外部关闭。网易云 GTK4 优先于浏览器等其他 MPRIS 播放器。

控制中心从左上入口下方打开，应用启动器保持居中。控制中心提供音量与静音、声音/网络/蓝牙设置入口、
常亮、勿扰、信息密度、壁纸和会话操作。CPU、RAM 与可用的 CPU 温度只在控制中心可见时采样，
使用轻量文字行。启动器用紧凑搜索列表，通知用小型浅粉横幅。

| 信息密度 | 默认 Quickshell 行为 |
| --- | --- |
| Balanced | 常规状态与时钟；宽屏显示日期 |
| Focus | 隐藏搜索、网络、日期和更新数量，保留音乐与关键状态入口 |
| Performance | 显示时钟秒数和音量百分比；硬件信息仍在控制中心 |

Waybar 保留为兼容后备，其三种布局不等同于 Quickshell 的胶囊交互。
Arch 更新入口显示官方仓库的检查结果，点击可重新检查或在终端查看待更新包；不会自动安装。
锁屏使用 gtklock 原生时钟、日期和认证表单，空闲时隐藏输入区域；swaylock 保留为后备。
输出缩放和输入设备差异留在本机覆盖中；配置部署不启用或切换登录会话。

系统应用使用 Noto Sans、Adwaita 图标与浅色偏好。`config/gtk-3.0/settings.ini` 和
`config/gtk-4.0/settings.ini` 按单文件部署，原件可恢复；Niri 中 Qt 使用 `gtk3` 平台主题。
GNOME/portal 的颜色偏好由 `scripts/desktop-appearance.py` 单独预览、备份与应用，影响当前用户的
GNOME 和 Niri 应用。应用自身的主题设置可能优先于系统偏好，不覆盖其账户或应用配置。

微调终端透明度可在本机 `~/.config/dotfiles-local/kitty.conf` 写入例如
`background_opacity 0.92`；提高数值能减弱壁纸对阅读的干扰。终端颜色集中在
`config/kitty/theme.conf`、`config/nvim/lua/dotfiles/ui.lua` 和 `config/lazygit/config.yml`；
浅色工具面板集中在 `config/desktop/panel.css`，顶部胶囊位于 `config/quickshell/desktop-island/`。

本次没有进行 macOS 图形验收。Linux 的解析、离屏与会话验证范围分别记录在
[验证记录](validation.md)；headless 检查不能替代字体、剪贴板或显示器上的视觉检查。

鼠标流程：点击文件树 → 双击文件 → 点击顶部标签切换 → 点击 Git 管理改动 → `q` 返回编辑。
键盘流程与鼠标并存：原生窗口、缓冲区和寄存器操作保持原样，文件树和 Git 也有快捷键。

## 终端颜色与配置不同

Shell 启动脚本也能通过 OSC 转义序列改写终端颜色。此次 Arch 的 Nyarch / pywal
在 `.bashrc` 中加载 `~/.cache/wal/sequences`，曾把仓库主题覆盖成暖棕色。
本机已备份并修正该加载条件，使 Kitty 使用仓库配色；shell 配置本身不纳入仓库。
如果新机器使用相同的桌面主题工具，可将原有 pywal 加载块限定为：

```bash
if [[ -z "${KITTY_WINDOW_ID:-}" && "${TERM:-}" != "xterm-kitty" && -f "$HOME/.cache/wal/sequences" ]]; then
    cat "$HOME/.cache/wal/sequences"
fi
```

修改后在 Kitty 按 `Ctrl-Shift-F5` 重载配置，或打开新窗口。相同颜色与不透明度仍会叠加
不同壁纸；macOS 的背景模糊与 Linux 合成器也可能呈现不同效果，因此不能保证像素颜色完全相同。
